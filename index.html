Conteúdos Curriculares

Trilha da Disciplina

Visão geral dos conceitos teóricos e práticos explorados ao longo das aulas de Programação Web.

Etapa 1

Estrutura com HTML5

Marcação semântica (header, nav, aside, main, section, footer), formulários acessíveis, links e organização de pastas no VS Code.

Etapa 2

Estilização com CSS3

Box model, Flexbox para alinhamentos, CSS Grid para layouts complexos, variáveis CSS, sombras e efeitos de transição/transform.

Etapa 3

Interatividade com JavaScript

Manipulação de elementos do DOM, eventos de clique, formulários interativos, alternância de classes e validações no navegador.

Etapa 4

Publicação & Versionamento

Controle de versão com Git, repositórios no GitHub e publicação contínua via GitHub Pages e Vercel.
