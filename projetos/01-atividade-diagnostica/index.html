Orientações da Atividade

Finalidade: Identificar os conhecimentos já desenvolvidos em HTML, CSS e JavaScript, para planejar a continuidade da disciplina.

Atenção: A atividade não valerá nota e não terá caráter punitivo. O objetivo é verificar o que cada estudante consegue desenvolver atualmente.

  • Modalidade: Individual
  • Duração: Duas aulas consecutivas
  • Entrega: Pasta zipada (diagnostico_nome_sobrenome)

A Situação Proposta

Você deverá construir a interface de um Portal de Projetos de Informática (exatamente como este que você está acessando!). A página deverá possuir um menu lateral, uma área principal de apresentação e um formulário de acesso simulado.

Requisitos Técnicos (HTML, CSS e JS)

1. HTML (Estrutura)

  • Menu lateral com pelo menos três opções.
  • Área principal com título e texto de apresentação.
  • Formulário de acesso (usuário, senha e botão).
  • Rodapé com identificação.

2. CSS (Estilo)

  • Uso de display: flex para organizar o layout (ex: menu ao lado do conteúdo).
  • Centralização de elementos.
  • Posicionamento relative ou absolute em algum elemento.
  • Uso de transform (ex: hover em botões).

3. JS (Interatividade)

  • Implementar pelo menos um evento ao clicar no botão de acesso.
  • Pode ser exibir mensagem, alterar texto, cor ou mostrar/esconder uma caixa.

Aspectos Observados

O foco da avaliação formativa será:

  • Organização dos arquivos e estrutura HTML.
  • Construção correta do menu, área principal e formulário.
  • Conexão entre HTML, CSS e JS.
  • Utilização correta do Flexbox, margens e alinhamentos.
  • Posicionamento (absolute/relative) e efeitos visuais (transform).
  • Criação de um evento interativo em JavaScript.
  • Autonomia e capacidade de explicar o próprio código.
Não se preocupe caso tenha dificuldades. Esta atividade servirá justamente para identificar o ponto de continuidade e orientar as próximas aulas!
